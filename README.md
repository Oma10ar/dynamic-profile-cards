# Dynamic Profile Cards (JavaScript & Flexbox)

A simple and practical project to dynamically generate and display profile cards using **JavaScript (DOM Manipulation)** and **CSS Flexbox**, complete with conditional avatar images based on gender (Male/Female).

---

## 🚀 Features

- **Dynamic Generation:** Programmatically create cards using a flexible JavaScript function (`elementCard`).
- **Responsive Layout:** Uses `Flexbox` with `flex-wrap` to automatically wrap cards into new lines based on screen size.
- **Conditional Assets:** Automatically sets the profile picture based on the input gender, complete with a fallback default image.
- **Clean Design:** Simple framing and centered layout for each profile card.

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3** (Flexbox, Responsive Wrapping)
- **JavaScript (ES6+)** (DOM Creation, Functions, If/Else Conditions)
